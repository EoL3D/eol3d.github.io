Benchmark: tasks and scoring

Each track fixes the input, the output, the metric and the evaluation set. A track with a released kit can be run now from the repository; the others come with a later release.

  1. Kit released

    Detection and instance segmentation

    Find every part in a top-down scanner image and give its class, box and mask.

    Input
    One scanner image, {{ det.frame_px }} × {{ det.frame_px }} pixels, taken after a step.
    Output
    Class, score, box and mask of each part, over {{ n.classes | num }} part classes. Masks are scored either as visible masks (a part in place but fully covered is an ignore region) or as complete (amodal) masks.
    Metric
    COCO AP averaged over IoU 0.50:0.95, for masks and boxes; also AP50, AP75, AP by size, AR, per-class AP and AP by occlusion. Mean AP is taken over the {{ det.classes_with_test | num }} classes that have test instances.
    Evaluation set
    The test split: {{ det.desktops.test | num }} desktops, {{ det.images.test | num }} images, {{ det.instances.test | num }} instances. Splits are by whole desktop (split and counts).
    Kit
    benchmarks/level1/: COCO split builder, scorer with a self-check, training and prediction scripts for a YOLO segmentation model and a Mask R-CNN.

    Run it: get started, evaluate

  2. Kit released

    Visual question answering

    Answer a question about a teardown from its images, as one JSON object.

    Input
    The images of a step from one or more cameras (two moments for questions about a change), with the parts in question outlined, and the question.
    Output
    A strict JSON answer in the task's format, e.g. a list of boxes, a state, a yes or no, or a removal plan.
    Metric
    Set per task: accuracy, exact match, F1, a box hit at IoU 0.5, or a replay of a plan on the relations (task table).
    Evaluation set
    eval_v3: {{ qa.eval | num }} questions over {{ n.qa_tasks | num }} tasks, drawn from all {{ n.desktops | num }} desktops; no desktop holds more than a fifth of a task. Each record also carries its desktop's train / test split in label.split.
    Kit
    vlm/vlmpack_2026-11-05/tools/: self-check, chat converter (OpenAI, Qwen-VL and InternVL formats), scorer with reference lines (chance, most frequent answer, question without its image).

    Run it: get started, evaluate

  3. Later release

    Metric depth from a single image

    Predict the depth of every pixel of one image, in millimetres.

    Input
    One image.
    Output
    A depth map in millimetres.
    Metric
    Compared with the depth the scanner measured: absolute relative error, RMSE and threshold accuracy.
    Evaluation set
    The reference depth maps come with a later release.
    Kit
    Comes with a later release.

    Kit not in the repository yet

  4. Later release

    Robot manipulation

    Remove a named part with a robot, with a policy learned from the robot demonstrations.

    Input
    The part to remove. Policies learn from {{ n.robot_demos | num }} robot demonstrations in two settings: Fixtured ({{ n.robot_fixtured | num }}) and On motherboard ({{ n.robot_on_board | num }}).
    Output
    Robot actions that take the part out.
    Metric
    Task success over repeated trials on the real robot.
    Evaluation set
    Comes with a later release.
    Kit
    The demonstrations are in the repository, under raw/robot/. The evaluation kit comes with a later release.

    Data released, kit to follow
