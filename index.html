About the dataset

EoL3D is a dataset of 66 end-of-life desktop computers, each taken apart by hand, one step at a time. After every step the machine is recorded from 4 fixed views. Instance masks, part states, removal relations, question-answer pairs, operator video and robot demonstrations are built on those records.

  • 66 66 end-of-life desktops
  • 2,748 2,748 disassembly steps
  • 84,225 84,225 instance annotations
  • 184,263 184,263 question-answer pairs

What is in the dataset

Each of the 66 desktops is recorded after every step of its teardown and annotated part by part. These are the parts of the release, shown with the dataset's own pictures.

One question-answer record, asked about the machine in the picture above:

Question
Looking at the machine in these pictures, which one of the following actions is possible right now?
Options
take out the RAM module; take out the motherboard; take out the CPU
Answer
{"verb": "remove", "target": "RAM module"}

    Detection and instance segmentation

    Find every part in a top-down scanner image and give its class, box and mask.

    Input
    One scanner image, 1600 × 1600 px
    Output
    Class, box and mask of each part, 24 classes
    Metric
    COCO AP for boxes and masks, IoU 0.50:0.95
    Run it

    Kit released

    Visual question answering

    Answer a question about a teardown from its images, as one JSON object.

    Input
    The images of a step and the question
    Output
    A strict JSON answer in the task's format
    Metric
    Set per task: accuracy, F1, a grounding score, plan replay
    Run it

    Kit released

    Depth from a single image

    Predict depth from one scanner image; the scanner's own 3D measurement is the reference.

    Input
    One scanner image
    Output
    A depth map
    Metric
    MAE, RMSE, relative error and threshold accuracy, as predicted and after one scale factor per image
    Run it

    Data released

    Robot disassembly

    Remove the part named in an instruction and put it in the sorting zone, on the real robot.

    Input
    The instruction, wrist and base camera images
    Output
    Arm and gripper actions
    Metric
    Trials completed within 150 s

    Download

    The data is on Hugging Face. One command fetches all of it; the guide shows how to take only the folders a task needs, read them and score a model.

    hf download ChangChrisLiu/E3D-Desktop-Disassembly --repo-type dataset --local-dir EoL3D
